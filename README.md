# Filament — filamentplatform.com

Marketing website for Filament, an AI-powered scholarship navigation platform for Canadian universities.

Single-page site built to convert university administrators into booked demo calls.

## Stack

- Next.js (App Router)
- Tailwind CSS
- Deployed on Vercel

## Dev

```bash
npm install
npm run dev
```

Opens at [http://localhost:3000](http://localhost:3000).

## Placeholders to replace

- **Calendly URL** — update `CALENDLY_URL` at the top of `app/page.tsx`
- **Contact email** — update `CONTACT_EMAIL` at the top of `app/page.tsx`
- **University logos** — add to the Social Proof section as deals close
